# PAC Dance Studio

Responsive static website for PAC Dance Studio, Vadodara, with a looping dance hero video, scroll animations, an accessible photo gallery, Google Maps and WhatsApp enquiries.

## Run locally

Serve this directory with any static HTTP server, for example:

```sh
python -m http.server 8080
```

Open http://localhost:8080. No dependencies or build step are required.

## Deploy

Deploy the repository root as a static website. For Vercel, select Other as the framework, leave the build command empty and use `.` as the output directory.
